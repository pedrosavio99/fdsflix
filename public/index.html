1 · Como funciona

Cada conta Vercel (plano Hobby) tem a própria cota de transferência (~100 GB/mês com o kit atual, que entrega pelo Edge; uma Vercel antiga rende 10 GB e é reconhecida sozinha: reenvie o kit para liberar). O vídeo passa pela Vercel, então cada conta nova no pool soma outra cota. Para cada filme/episódio o fdsFlix escolhe a Vercel com mais cota sobrando (sorteia só no empate); se ela falhar, tenta a próxima (até 3). Um filme inteiro sai de uma Vercel só.

Contas diferentes, não projetos diferentes: vários projetos na mesma conta não somam. 1080p gasta ≈ 2,2 GB por hora assistida. Existe também um limite de chamadas de função (cada segmento é uma; ≈ 1.700 por filme de 2 h): confira em Usage.

2 · Passo a passo: subir uma Vercel nova

Faça uma vez por conta. Precisa de Node 20+ e uma conta Vercel nova (e-mail diferente, já confirmado). Não há variável nenhuma para configurar: PROXY_SECRET e TARGET_ORIGIN já vêm embutidas no código do kit (arquivo lib/config.js).

  1. Descompacte o zip e entre na pasta: 
    unzip fdsflix-vercel-kit.zip
cd adproxy-kit
  2. Entre na conta Vercel desta vez (saia da anterior antes): 
    npx vercel logout
npx vercel login
  3. Rode o script. Ele cria o projeto e publica em produção: 
    bash deploy-vercel.sh
  4. Anote a URL de produção curta (https://adproxy-kit.vercel.app ou parecida; em Project → Domains, não a de um deploy avulso com hash) e teste: 
    curl -s "https://SEU-DOMINIO.vercel.app/vidsrc/probe?tmdb=603"
    Se voltar uma página HTML de login: Project → Settings → Deployment Protection e desligue para Production.
  5. Repita 2–4 em cada conta e cole as URLs no Render (seção 3).

Sem o script: dentro da pasta, npx vercel link --yes e npx vercel deploy --prod --yes. A ligação GitHub↔Vercel costuma aceitar uma conta só; por isso o caminho é pela linha de comando.

3 · Colocar as URLs novas no Render

No Render (fdsFlix) → Environment, a variável VIDSRC_PROXY_URLS guarda todas as URLs de produção, separadas por vírgula. Cada Vercel nova: acrescente a URL dela e salve (o Render faz redeploy). Cole as URLs abaixo (uma por linha, ou separadas por vírgula/espaço) e copie a linha pronta:

VIDSRC_PROXY_URLS=

Mais duas variáveis no Render, uma vez só: VERCEL_QUOTA_GB=100 (cota de uma Vercel no Edge) e USAGE_RESET_DAY=1 (dia em que a cota renova; veja em Usage na Vercel). Depois do redeploy, no seu PC: npm run pool:check. O botão Testar Vidsrc/Vercel do diagnóstico testa todas pelo servidor.

4 · Valores embutidos (PROXY_SECRET e TARGET_ORIGIN)

Vêm fixos no código: TARGET_ORIGIN = https://vidlink.pro (site do modo AdShield, só na rota /; o pool de vídeo nem usa) e um PROXY_SECRET de 64 caracteres que assina as URLs de vídeo. O mesmo valor vale em todas as contas.

O segredo é público por decisão do dono do projeto: quem o souber consegue assinar URLs e usar a Vercel como proxy aberto. Para trocar, defina PROXY_SECRET nas variáveis da Vercel (a variável manda mais) ou mude BUILTIN_PROXY_SECRET em lib/config.js e publique de novo. Trocar só obriga a recarregar um filme que estava tocando.

7 · Atualizar o código depois

Baixe um kit novo e rode bash deploy-vercel.sh em cada conta (logout/login entre elas).

8 · Problemas comuns
  1. 404 "deployment not found": URL errada ou projeto apagado. Copie a de produção em Domains.
  2. Probe devolve HTML de login / 401: Deployment Protection ligada. Desligue para Production.
  3. 403 "URL não assinada pelo proxy": o PROXY_SECRET mudou com o player aberto. Recarregue o título.
  4. O script falha em link/deploy: CLI antiga ou não logado. npx vercel@latest login e rode de novo.
  5. Uma Vercel nunca é escolhida: está ≥ 98 % ou falhando. Veja o diagnóstico e rode pool:check.
  6. Selo do histórico vermelho: leia a mensagem ao lado dele. "tabelas não criadas" = rode o SQL (seção 5); "chave recusada" = confira SUPABASE_SECRET_KEY no Render.
  7. Esgotou antes pelas chamadas de função: o limite Function Invocations aperta antes da banda. Confira em Usage.
O plano Hobby da Vercel é de uso pessoal e não comercial; várias contas só para somar cota podem ferir os termos e levar à suspensão. A decisão e o risco são seus.
